# invest-os

台指期當沖自動交易程式。每天早上比三個開盤價決定做多或做空，下午收盤前平掉，
**部位不過夜**。

跑在一台 Windows 電腦上，由工作排程器每天叫醒兩次。裝好之後你不需要做任何事，
只要看 Discord。

---

## ⚠️ 先確認你有這些，不然裝了也不能用

| | 大概要多久 |
|---|---|
| 群益證券的**期貨帳戶**，且已簽「期貨 API 下單同意書」並開通 | **好幾天**，要等券商作業 |
| 群益的 API 元件裝在這台電腦上（要用系統管理員身分安裝） | 15 分鐘 |
| **下單憑證**（綁這台電腦，申請時會收簡訊） | 30 分鐘 |
| 一個 Discord webhook 網址（通知用） | 5 分鐘 |

前三項的申請與安裝步驟見 [docs/LOGIN_SETUP.md](docs/LOGIN_SETUP.md)。

> 📌 **看報價不需要憑證，只有送出委託需要。**
> 所以你可能會一路都正常 —— 訊號有、通知有 —— 直到真的要下單那一刻才被擋下來。

---

## 裝起來（四步）

**1. 解壓縮**到一個固定的位置，之後不要再搬動它。

**2. 填帳密**：把 `.env.example` 複製一份改名成 `.env`，填四個值。

```
CAPITAL_USER_ID           身分證字號
CAPITAL_PASSWORD          群益登入密碼
CAPITAL_FUTURES_ACCOUNT   分公司代碼 4 碼 + 帳號 7 碼
DISCORD_WEBHOOK_URL       通知用
```

**3. 填設定**：打開 `config\settings.yaml`。每一項都寫了設錯會怎樣。

> ⚠️ **`auto_enabled` 出廠是關的。** 關著的時候程式只算訊號、發通知，
> **完全不會下單**。先這樣跑幾天，確認每天早上都收得到訊息再打開。

**4. 建立排程**：在這個資料夾按右鍵 →「在終端中開啟」，輸入

```powershell
.\setup_schedule.ps1
```

會建立兩個每天執行的工作：**08:50 進場**、**13:40 出場**。

---

## 之後每天

**早上收到一則訊號訊息 = 一切正常。** 下午正常出場不會再發訊息 —— 沒消息就是好消息。

收到其他訊息時 → **[docs/MESSAGES.md](docs/MESSAGES.md)** 告訴你那是什麼、你要做什麼。

⚠️ **平日早上沒收到訊息 = 排程掛了。** 那是唯一的偵測機制。重建：`.\setup_schedule.ps1`

---

## 還要確認兩件事

**電腦不能睡著。** 睡著就不會醒來跑。

```powershell
powercfg /query SCHEME_CURRENT SUB_SLEEP    # 待機、休眠都要是 0（永不）
```

**要能自動登入。** 憑證裝在你的 Windows 帳號底下，排程必須在你登入的狀態才跑得起來 ——
所以半夜 Windows 更新重開之後，要能自動登回桌面。

## 檔案在哪

```
osmain.exe            程式本體
_internal\            程式用的東西，不要動
config\settings.yaml  ← 你填這個
.env                  ← 你填這個（自己從 .env.example 複製）
logs\                 每天的執行紀錄，保留 30 天後自動清除
state\                今天的部位、以及每天的開盤價紀錄
setup_schedule.ps1    建立／查看／移除排程
```

⚠️ **`logs\` 不要整包傳給任何人。** 裡面有券商回覆的原始內容（含期貨帳號），
以及群益元件自己寫的日誌（含身分證字號）。

⚠️ **換電腦的時候要把 `state\` 一起複製過去。** 裡面是重建不回來的紀錄。
（憑證不能複製，要在新電腦重新申請。）

---

## 想暫停

**不想交易但想繼續收訊號** → `config\settings.yaml` 把 `auto_enabled` 改成 `false`

**完全停掉** → `.\setup_schedule.ps1 -Remove`

> 建議用前者。後者會連早上那則訊號都沒有 —— 而那則訊號同時是
> 「排程還活著」的唯一證據，停掉之後你不會知道自己忘了打開。
