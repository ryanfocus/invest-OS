# invest-os

台指期當沖自動交易程式。每天早上比三個開盤價決定做多或做空，下午收盤前平掉，
**部位不過夜**。

跑在一台 Windows 電腦上，由工作排程器每天叫醒兩次。裝好之後你不需要做任何事，
只要看 Discord。

---

## ⚠️ 先確認你有這些，不然裝了也不能用

| | 大概要多久 |
|---|---|
| 群益證券的**期貨帳戶**，且已簽「期貨 API 下單同意書」並生效 | **好幾天**，要等券商 |
| 群益的 API 元件裝在這台電腦上（**64 位元**，要用系統管理員） | 15 分鐘 |
| **下單憑證**（綁這台電腦，申請時會收簡訊） | 30 分鐘 |
| 一個 Discord webhook 網址（通知用） | 5 分鐘 |

**步驟都在 [docs/LOGIN_SETUP.md](docs/LOGIN_SETUP.md)。先去辦第一項，它最花時間。**

## 裝起來

### 0. 放對地方

解壓縮到**你自己寫得進去的位置**，例如 `C:\Users\<你的名字>\invest-os`。
之後不要再搬動它。

⚠️ **不要放在 `C:\Program Files\` 或磁碟根目錄。** 那些地方一般帳號寫不進去，
而程式每天需要在自己的資料夾裡寫紀錄。

### 1. 填帳密

把 `.env.example` 複製一份改名成 `.env`，用記事本打開填四個值：

```
CAPITAL_USER_ID           身分證字號
CAPITAL_PASSWORD          群益登入密碼
CAPITAL_FUTURES_ACCOUNT   先留空，第 3 步會查出來
DISCORD_WEBHOOK_URL       通知用
```

⚠️ **存檔時編碼要選 UTF-8。** 記事本預設就是，但如果你用別的編輯器存成
「ANSI」或「Big5」，程式會在啟動時掛掉而且**不會發任何通知**。
`config\settings.yaml` 也一樣。

### 2. 填設定

打開 `config\settings.yaml`。每一項都寫了設錯會怎樣。

> ⚠️ **`auto_enabled` 出廠是關的。** 關著時程式只算訊號、發通知，**完全不會下單**。
> 先這樣跑幾天，確認每天早上都收得到訊息，再打開。

### 3. 查出你的期貨帳號

**雙擊 `show-account.cmd`**，把【市場為 TF】那一筆的完整帳號填回 `.env`。

### 4. 建立排程

**雙擊 `setup-schedule.cmd`**。會建立兩個每天執行的工作：**08:50 進場**、**13:40 出場**。

> 📌 第一次執行 `.cmd` 時 Windows 可能跳出藍色的「已保護您的電腦」畫面
> （SmartScreen）。這支程式沒有數位簽章，那是預期的 —— 點「其他資訊」→「仍要執行」。
> 防毒軟體偶爾也會誤判，需要的話把整個資料夾加入排除清單。

## 之後每天

**早上收到一則訊號訊息 = 一切正常。** 下午正常出場不會再發訊息 —— 沒消息就是好消息。

收到其他訊息時 → **[docs/MESSAGES.md](docs/MESSAGES.md)** 告訴你那是什麼、你要做什麼。

### 平日早上沒收到訊息，代表兩件事之一

1. **排程沒跑起來** → 雙擊 `show-schedule.cmd` 看它還在不在，不在就重跑 `setup-schedule.cmd`
2. **程式跑了但當掉了** → 排程看起來正常，但那天的紀錄裡會有錯誤

分辨方法：打開 `logs\entry-<當天日期>.log`。

- **檔案不存在** → 排程沒跑
- **檔案裡有一堆紅字或 `Traceback`** → 程式當掉了，見下面「出事的時候」

⚠️ **下午那班當掉是最危險的**，因為它本來就不發訊息 —— 你不會察覺，
而部位會過夜。所以早上收到訊號、確認有下單的那些日子，
偶爾看一下 `logs\exit-<日期>.log` 有沒有「出場完成」。

---

## 還要確認兩件事

**電腦不能睡著。** 睡著就不會醒來跑。

```powershell
powercfg /query SCHEME_CURRENT SUB_SLEEP    # 待機、休眠都要是 0（永不）
```

**要能自動登入。** 憑證裝在你的 Windows 帳號底下，排程必須在你登入的狀態才跑得起來 ——
所以半夜 Windows 更新重開之後，要能自動登回桌面。

## 出事的時候，把這些給我

```
1. Discord 那則訊息（原文複製）
2. logs\entry-<當天>.log 與 logs\exit-<當天>.log 這兩個檔
3. BUILD.txt 的內容（一行字，標明你這份是哪一版）
```

⚠️ **只傳那兩個 `.log` 檔，不要整個 `logs\` 資料夾。**
同一個資料夾裡還有券商回覆的原始內容（`replies-*.txt`，含期貨帳號）
以及群益元件自己寫的日誌（`Center.log` 之類，**含身分證字號**）。
那些不要傳給任何人。

## 檔案在哪

```
osmain.exe            程式本體
_internal\            程式用的東西，不要動
BUILD.txt             這份是哪一版（出事回報時要附）
config\settings.yaml  ← 你填這個
.env                  ← 你填這個（自己從 .env.example 複製）
logs\                 每天的執行紀錄，保留 30 天後自動清除
state\                今天的部位、以及每天的開盤價紀錄

show-account.cmd      查出你的期貨帳號
setup-schedule.cmd    建立（或重建）排程
show-schedule.cmd     看排程現況，唯讀
remove-schedule.cmd   移除排程，程式完全停止

run_stage.cmd         排程實際執行的東西，**不要刪**——每天的紀錄全靠它產生
setup_schedule.ps1    上面那幾個 .cmd 實際呼叫的腳本
```

⚠️ **換電腦的時候要把 `state\` 一起複製過去。** 裡面是重建不回來的紀錄。
（憑證不能複製，要在新電腦重新申請。）

## 想暫停

**不想交易但想繼續收訊號** → `config\settings.yaml` 把 `auto_enabled` 改成 `false`

**完全停掉** → 雙擊 `remove-schedule.cmd`

> 建議用前者。後者會連早上那則訊號都沒有 —— 而那則訊號同時是
> 「排程還活著」的唯一證據，停掉之後你不會知道自己忘了打開。
