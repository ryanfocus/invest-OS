# 安裝設定 — 一步一步做

程式本身不用安裝（解壓縮就好），但它要透過**群益的下單元件**才能連上市場，
而那部分要你自己準備。這份文件講的就是那部分。

⚠️ **最花時間的是第 1 步，而且要等券商作業（好幾天）。** 先去辦，其他的可以並行。

```
1  簽「期貨API服務下單聲明書」   ← 要等券商，好幾天
2  申請下單憑證                  30 分（含簡訊驗證）
3  跑官方連線測試                10 分  不做的話登入會被擋（錯誤碼 321）
4  安裝群益的 API 元件           15 分  要用系統管理員
5  查出你的期貨帳號、填設定       5 分
```

---

## Step 1 — 簽署「期貨API服務下單聲明書」

**沒簽的話，程式登入得進去，但查不到你的期貨帳號，也不能下單。**

管道任選一個：

- **官網**：<https://tradeweb.capital.com.tw/Login.aspx?Source=L&Action=TSWEB/agreeList.aspx>
- **群益行動贏家 APP** → 客戶服務 → 電子單據 → 聲明書
- **掌中財神全球通 APP** → 相同位置

簽完通常隔一個工作天生效。不確定的話打給你的營業員問「期貨 API 下單聲明書生效了嗎」。

---

## Step 2 — 申請並安裝下單憑證

進 [群益金融網](https://www.capital.com.tw/web/) → **憑證專區 → AP軟體憑證** → 依指示申請。
過程中會收一次簡訊驗證碼。

⚠️ **憑證是綁這台電腦的。** 換電腦要重新申請，舊的複製過去沒有用。

⚠️ **看報價不需要憑證，只有送出委託需要。**
所以你可能會一路都正常 —— 收得到訊號、Discord 也有 —— 直到真的要下單那一刻
才被擋下來，錯誤碼是 **1038**。

---

## Step 3 — 跑官方連線測試

**沒做的話登入會直接被擋，錯誤碼 321：測試未完成。**

1. 到群益的 [API 下載專區](https://www.capital.com.tw/web/#/download/ApiTrading/ApiTradinginfo)
   下載驗證小工具 `SKCOMVerifyDJ.exe`
2. 執行它，用你的身分證字號與密碼登入
3. 顯示測試通過就完成了

---

## Step 4 — 安裝群益的 API 元件

### 4-1 一定要用 **64 位元** 那組

本程式是 64 位元的。**裝成 32 位元的話，程式會說「SKCOM 元件尚未註冊」**，
而你明明已經裝了 —— 那個訊息會把你帶偏。

### 4-2 下載並放到固定位置

從上面同一個[下載專區](https://www.capital.com.tw/web/#/download/ApiTrading/ApiTradinginfo)
取得元件，把 **x64** 那一組**整組**複製到 `C:\SKCOM`（官方建議的位置）。

⚠️ **要整組複製，不能只搬 `SKCOM.dll`。** 官方文件明講元件與憑證元件要放在一起。

### 4-3 註冊

在 `C:\SKCOM` 資料夾按右鍵 →「**在終端中開啟（系統管理員）**」，然後：

```
install.bat
```

**一定要是系統管理員**，不然註冊會失敗而且不一定會報錯。

---

## Step 5 — 查出你的期貨帳號

回到程式的資料夾，**雙擊 `show-account.cmd`**。

它會登入群益、把你可以下單的帳號列出來：

```
  市場    完整帳號          姓名
  TF      F9990012345      王小明
```

把**市場為 TF** 那一筆的完整帳號，填進 `.env` 的 `CAPITAL_FUTURES_ACCOUNT`。

> ⚠️ 那是完整帳號，**不要把這個畫面貼給任何人**。

**查不到任何帳號** = 幾乎一定是 Step 1 的聲明書還沒生效。等一個工作天再試。

---

## 常見錯誤

| 錯誤 | 意思 | 怎麼辦 |
|---|---|---|
| **321** 測試未完成 | Step 3 沒做 | 跑 `SKCOMVerifyDJ.exe` |
| **1038** 憑證未驗證 | Step 2 沒做，或憑證過期 | 重新申請憑證 |
| **SKCOM 元件尚未註冊** | Step 4 沒做，或裝成 32 位元 | 用 x64 那組，以管理員執行 `install.bat` |
| 查不到帳號 | Step 1 的聲明書還沒生效 | 等一個工作天，或問營業員 |

---

## 換電腦的時候

| | 要重做嗎 |
|---|---|
| 程式本身 | 複製整個資料夾就好 |
| 群益元件 | **要重裝**（Step 4） |
| 憑證 | **要重新申請**（綁電腦，不能複製） |
| `.env`、`config\settings.yaml` | 複製過去就好 |
| **`state\` 資料夾** | **要複製**，裡面是重建不回來的紀錄 |
| 排程 | 在新電腦雙擊 `setup-schedule.cmd` |
