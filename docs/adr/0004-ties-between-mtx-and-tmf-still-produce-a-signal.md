# 小台與微台開盤價相等時，仍然產生訊號

訊號判定完全依照策略作者給的公式：`大台 > 小台 and 大台 > 微台` → 做多，
`大台 < 小台 and 大台 < 微台` → 做空。**小台與微台彼此是否相等，與判定無關。**

所以「大台 30271、小台 30285、微台 30285」判為**做空**——兩個條件都成立。
只有當**大台**與小台或微台相等時才不成立（不構成純大於／純小於），該情況為不動作。

## Consequences

這不是邊緣案例。以期交所 2026/01–07 共 126 個交易日的官方開盤價統計：

| 情況 | 天數 | 訊號 |
|------|------|------|
| 大台 == 小台，或 大台 == 微台 | 4（3.2%） | 不動作 |
| **小台 == 微台，大台不同** | **20（15.9%）** | **照常做多／做空** |
| 三者全等 | 0 | 不動作 |

若改採另一種讀法（「有任兩個價格相等就不動作」），這 20 天會全部變成空手——
約每六個交易日就有一天結論相反。

需求文件早期的措辭（「兩兩相等 → 不動作」）曾經指向那個讀法，是整理需求時的
過度延伸，非策略作者原意。相關措辭已在 `CONTEXT.md`、`docs/SPEC.md`、
與 ticket 01 全面更正。

**給未來讀到這段程式碼的人**：`strategy.compute` 對相等的處理是刻意的，不是漏判。
在改動它之前先讀這份 ADR——把它「修成」有相等就不動作，會靜默改變 15.9% 交易日的行為，
並使實盤結果偏離策略作者的回測基準。
