# 群益 API 登入設定 — 一步一步做

> 目標：讓程式能在**無人值守**的情況下自動登入群益、取得報價、送出委託。
> 全部做完之後，程式只需要帳號密碼就能登入——**不會跳視窗、不會要簡訊驗證碼**。

---

## 先搞懂一件事：什麼是「雙因子」

群益從 2021 年起強制雙因子登入。很多人以為這代表「每次登入都要收簡訊」，**不是**。

| 因子 | 是什麼 | 誰提供 |
|------|--------|--------|
| 第一因子 | 身分證字號 + 密碼 | 程式從設定檔讀 |
| 第二因子 | **安裝在這台電腦上的憑證檔** | 電腦本身 |

所以「第二因子」是一次性安裝的檔案，不是每次要輸入的東西。
**只有申請憑證的那一次會收簡訊驗證碼**，之後就不用了。

這也是為什麼程式可以自動跑——你人在忙、在開會、在睡覺都不影響。

---

## 全部步驟總覽

```
Step 1  申請 API 使用權限        ← 要等群益開通
Step 2  申請並安裝下單憑證        ← 會收一次簡訊驗證碼
Step 3  跑官方連線測試            ← 不做的話登入會被擋（錯誤碼 321）
Step 4  註冊 COM 元件（這台電腦） ← 需要系統管理員
Step 5  安裝 Python 套件
Step 6  驗證能不能登入
```

Step 1～3 是**跟群益之間的手續**，有等待時間，可以先跑。
Step 4～6 是**這台電腦的環境設定**，隨時可做。

---

## Step 1 — 簽署「期貨API服務下單聲明書」

⚠️ **前置條件：必須已完成期貨開戶。** 只有證券帳戶不行——我們要下的是台指期。

三個管道任選一個，簽的都是同一份文件：

### 管道 A：官網（最直接）

1. 開 **<https://tradeweb.capital.com.tw/Login.aspx?Source=L&Action=TSWEB/agreeList.aspx>**
2. 輸入**身分證字號**與**網路交易密碼**登入
3. 在清單中找到**國內期貨**的「**期貨API服務下單聲明書**」
4. 詳閱後打勾 → 點【同意】

### 管道 B：群益行動贏家 APP

登入 → 點「同意書簽署」→ 下滑找到國內期貨的「期貨API服務下單聲明書」→ 打勾 → 同意

### 管道 C：掌中財神全球通 APP

點下方「同意書專區」→ 輸入身分證字號與網路交易密碼 → 下滑找到同一份 → 打勾 → 同意

---

- 沒有簽署的話，程式**連元件都初始化不了**，不是登入失敗而已
- 這步要等群益作業，不是即時開通
- 卡住的話直接問你的營業員，這是他們的例行作業

**怎麼確認完成**：同意書清單中該項顯示已簽署，且營業員回覆 API 權限已開通。

**元件下載**（Step 3 的驗證工具 `SKCOMVerifyDJ.exe` 也在這裡）：
<https://www.capital.com.tw/web/#/download/ApiTrading/ApiTradinginfo>

---

## Step 2 — 申請並安裝下單憑證

這是「第二因子」，也是唯一會收簡訊的一步。

1. 進 [群益金融網](https://www.capital.com.tw/web/) → 點「**憑證專區 → AP軟體憑證**」
2. 點「**立即申請/展延**」→ 下載**憑證精靈**（檔名 `RAWinApp`）
3. 執行憑證精靈 → 輸入你的「**身分證字號**」+「**密碼**」登入
4. 點「**申請**」
5. 詳閱「CA憑證申請同意書」→ 點「**我同意**」→ 會自動跳到「憑證作業」網頁
6. 依畫面步驟：**驗證身分 → 寄發驗證碼 → 收取驗證碼**（簡訊）→ 回到憑證精靈畫面
7. 輸入驗證碼 → **等 5～20 秒**下載憑證資料
8. 點「**檢測憑證請按此**」

**怎麼確認完成**：狀態顯示「**此電腦已安裝您的有效憑證**」。

> ⚠️ **憑證是綁這台電腦的。** 換電腦要重做這一步。
>
> ⚠️ **不要讓電腦裡同時存在兩張憑證**（例如舊的過期的沒刪）。
> 這會造成登入錯誤碼 600，而且訊息不會告訴你原因是「有兩張」。

---

## Step 3 — 跑官方連線測試

**這步不能跳過。** 主管機關規定使用正式 API 前必須先完成連線測試，
沒做的話登入會直接回**錯誤碼 321：測試未完成**。

1. 到群益 [API 下載專區](https://www.capital.com.tw/web/#/download/ApiTrading/ApiTradinginfo) 下載驗證小工具 `SKCOMVerifyDJ.exe`
2. 執行它，完成兩件事：
   - **雙因子登入**測試
   - **下單測試（國內期貨）** ← 我們要用的是期貨，做這項

**怎麼確認完成**：小工具顯示測試通過。之後用程式登入就不會再看到 321。

---

## Step 4 — 註冊 COM 元件（這台電腦）

群益的 API 是 Windows 的 ActiveX COM 元件，用之前必須先「註冊」到系統。

### 4-1 先確認位元數

這台電腦的 Python 是 **64 位元**（已確認：3.12.4 64-bit），所以要用 **x64** 那組元件。
兩者位元數不一致的話，程式會在建立物件時失敗。

### 4-2 把元件複製到固定位置

⚠️ **註冊會把「DLL 當下的絕對路徑」寫進系統登錄檔。** 之後那個資料夾一旦被搬走或改名，
COM 就壞了。所以要先放到一個**永遠不會動**的位置。

官方建議 `C:\SKCOM`。把這個資料夾**整組**複製過去：

```
D:\project\量化交易\DeplyedInvestStrategy\CapitalAPI_2.13.58_PythonExample\元件\x64\
```

⚠️ **要整組複製，不能只搬 `SKCOM.dll`。** 官方文件明講「SKCOM.dll、COM元件與憑證元件、
報價元件需放在同一資料夾內再進行元件註冊」。那個資料夾裡有 8 個 DLL，全部都要。

### 4-3 執行註冊

1. 在開始選單搜尋「命令提示字元」→ **右鍵 → 以系統管理員身分執行**
2. 執行：

```
cd C:\SKCOM
install.bat
```

`install.bat` 的內容就是 `regsvr32.exe "C:\SKCOM\SKCOM.dll"`，很單純。

**怎麼確認完成**：跳出視窗顯示「DllRegisterServer 成功」。

> 如果失敗，通常是缺 **Visual C++ 可轉散發套件**。
> 到微軟官網下載 `vcredist_x64.exe` 裝好再試一次。

> **要反悔**：同一個資料夾有 `Uninstall.bat`，一樣用系統管理員執行，可以解除註冊。

---

## Step 5 — 安裝 Python 套件

用專案的虛擬環境裝兩個套件：

```
pip install comtypes pywin32
```

- `comtypes` — 讓 Python 呼叫 COM 元件
- `pywin32` — Windows 相關功能

> 官方文件寫的是 Python 3.8 + comtypes 1.2.0，我們用的是 3.12.4。
> 版本差距不小，如果 Step 6 出現奇怪的錯誤，可以先試著把 comtypes 降到官方版本。

---

## Step 6 — 驗證能不能登入

專案裡有一支驗證程式，跑它就知道每一步是否到位：

```
python tools/verify_login.py
```

它會依序檢查並印出結果：

1. Python 位元數對不對
2. COM 元件註冊了沒
3. 能不能登入
4. **列出期貨商品清單** ← 順便確認微台的正確代號
5. **取得三個開盤價** ← 順便確認拿到的是日盤還是夜盤的價格

第 4、5 項是目前專案卡住的兩個問題，這支程式跑完就有答案。

執行前先建立 `.env`（複製 `.env.example` 改名），填入帳號密碼。

> ⚠️ `.env` 已被 `.gitignore` 排除，不會進版控。**但也不要用任何方式貼給別人看。**

## 常見錯誤代碼對照

登入失敗時程式會印出代碼，對照這張表：

| 代碼 | 意思 | 怎麼處理 |
|------|------|---------|
| **321** | 測試未完成 | 回 Step 3，跑 `SKCOMVerifyDJ.exe` |
| **300** | 密碼驗證失敗 | 密碼打錯了 |
| **306** | 身分證字號錯誤 | 帳號打錯了 |
| **307** | 密碼被鎖定 | 到群益金融網「密碼專區」解鎖 |
| **600** | 驗證憑證錯誤 | 沒裝憑證，**或電腦裡有兩張憑證** → 刪掉過期的那張 |
| **602 / 603** | 雙因子登入失敗 | 憑證沒裝或不是登入 ID 本人的 |
| **604** | 憑證過期或已註銷 | 回 Step 2 重新申請 |
| **507** | 驗證裝置碼失敗 | 裝置碼未綁定，可透過「策略王」軟體綁定 |
| **101** | 登入 token 異常 | 重新登入即可 |
| **1008** | 憑證過期或無效 | 同 604 |
| **1128** | WebCA 憑證初始失敗 | 憑證元件沒跟 SKCOM.dll 放同一資料夾 → 回 Step 4-2 |
| **1109** | 未取得時效 token | 重新登入。這是正常的 token 過期 |
| **1127** | 一分鐘內查詢超過 10 次 | 降低呼叫頻率 |

## 換電腦時要重做哪些

| Step | 要重做嗎 |
|------|---------|
| 1 申請 API 權限 | ❌ 不用，權限綁帳號 |
| 2 安裝憑證 | ✅ **要**，憑證綁電腦 |
| 3 連線測試 | ❌ 不用 |
| 4 註冊 COM | ✅ **要** |
| 5 Python 套件 | ✅ 要 |
| 6 驗證 | ✅ 要 |

---

## 做完之後

程式就能自動登入了。接下來每天 08:50 和 13:40，Windows 工作排程器會叫醒程式，
它自己登入、自己取價、自己判斷、自己下單，你只會在 Discord 收到結果。

⚠️ **但自動下單先不要開。** 專案有三件事必須在真機驗證後才能開啟下單，
其中最關鍵的是「開盤價到底是日盤還是夜盤的」——那個錯了會讓**每天的訊號都是錯的，
而且從數字完全看不出來**。Step 6 的驗證程式就是為了回答這題。
