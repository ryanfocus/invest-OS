# 07 — 排程與部署

**What to build:** 程式不再需要人工執行。Windows 工作排程器在進場與出場時間各叫醒它一次，
完整跑過一個交易日——早上收到訊號通知，下午正常出場。

**Blocked by:** 05

**Status:** ready-for-agent

- [ ] 工作排程器有兩個工作，分別在進場與出場時間觸發
- [ ] 已處理電腦睡眠問題：能被喚醒執行，或已確認該機器不會進入睡眠
- [ ] 排程執行時的工作目錄與環境正確，程式找得到設定檔與狀態檔
      （這是 cron/排程最常見的失敗原因）
- [ ] 執行紀錄寫入 log 檔並保留
- [ ] 完整跑過一個真實交易日並驗收
- [ ] 部署與接手文件完成，含「換機器時要重做哪些步驟」
