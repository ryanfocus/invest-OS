# 07 — 隔日對帳

**What to build:** 隔天早上，在當日的訊號、通知、下單全部完成**之後**，
程式比對前一交易日記錄的三個開盤價與期交所官方資料。不一致就發 Discord。

這是唯一能抓到「開盤價取到錯誤盤別」這類系統性錯誤的機制——那種錯誤會讓每天的訊號都錯，
但從數字本身完全看不出來。它是純加分功能，偶爾失敗只是少檢查一天。

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] 對帳在訊號發報與下單全部完成之後才執行，時序上不可能耽誤當日策略
- [ ] 對帳的任何失敗（網路、格式、例外）都不影響當日策略，也不改變程式的結束狀態
- [ ] 官方資料的日期與狀態檔記錄的日期不符時**靜默跳過**，不視為失敗
      （開機第一天、連假、上次沒跑，都屬此類）
- [ ] 三個開盤價與官方資料一致 → 只寫 log
- [ ] 任一不一致 → 發 Discord，指明哪個商品、兩邊各是多少
- [ ] 比對在數值域進行，不比對字串
