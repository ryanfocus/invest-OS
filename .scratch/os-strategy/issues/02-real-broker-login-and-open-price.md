# 02 — 真實 broker：登入與取得開盤價

**What to build:** 把假 broker 換成真的群益 API。程式用設定檔裡的帳密自動登入、
訂閱三個商品、取得當日開盤價，Discord 收到的是**真實數字**。人不需要在場、不需要輸入任何東西。

這張是全案的閘門：它同時回答「微台的商品代號是什麼」和「開盤價是日盤還是夜盤」，
後者沒確認之前，後續所有下單功能都不該啟用。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 程式以設定檔中的帳密自動登入，全程不需人工輸入驗證碼或點選視窗
- [ ] 取得三個商品的開盤價，數值已還原小數（群益回傳為整數且放大 100 倍）
- [ ] 開盤價為 0 視為「資料未就緒」，等待一分鐘後重試，最多三次
- [ ] 開盤價不落在跌停價與漲停價之間時同樣視為未就緒並重試
- [ ] 三次重試後仍取不到 → 發 Discord 告知當日無訊號，程式正常結束
- [ ] COM 元件的初始化**不在模組載入時發生**；未註冊 COM 的機器仍可 import 並執行全部測試
- [ ] 微台的商品代號已由商品清單查詢實機確認，結果更新回 CONTEXT.md
- [ ] 開盤價已與期交所官方資料對照，**確認為 AM 盤（日盤）而非全盤**，結果記錄在案
- [ ] 假 broker 與真實 broker 通過同一組行為測試
