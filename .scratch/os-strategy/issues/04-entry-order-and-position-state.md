# 04 — 進場下單、狀態檔與開關

**What to build:** 自動下單開關關閉時，程式只發訊號、完全不碰下單 API。
開關開啟時，依訊號方向送出市價 IOC 委託，並在收到成交回報後把**實際成交口數**記進狀態檔——
那份記錄是下午出場時唯一的依據。

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 自動下單開關**預設為關閉**
- [ ] 開關關閉時，broker 的下單函式**一次都沒有被呼叫**（由測試證明，不是靠讀程式碼相信）
- [ ] 開關開啟且訊號為做多或做空 → 送出市價 IOC 委託，口數為使用者設定值
- [ ] 訊號為不動作 → 不送出任何委託
- [ ] 委託**不標記當沖**
- [ ] 交易標的（大台／小台／微台）與口數由設定檔決定，程式不檢查槓桿或保證金
- [ ] 收到成交回報後，把**實際成交口數**（非委託口數）寫入狀態檔
- [ ] 狀態檔以原子方式寫入，中斷不會留下半個檔案
- [ ] 狀態檔已有當日記錄時，重複執行不會再次下單
- [ ] Discord 訊號發報在下單**之前**完成，下單失敗不影響訊號送達
- [ ] 倉別參數（新倉／自動）的正確值已在測試環境實機驗證並記錄
