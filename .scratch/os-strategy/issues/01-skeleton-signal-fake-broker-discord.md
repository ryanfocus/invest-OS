# 01 — 專案骨架 + 訊號計算 + 假 broker + Discord

**What to build:** 執行一次進場流程，程式從假 broker 取得大台、小台、微台的開盤價，
判斷出當日訊號方向，並把三個開盤價與方向發到 Discord。整條鏈端到端可跑通，只是資料是假的。

這是整個專案的第一顆曳光彈——之後每一張 ticket 都是把這條鏈上的某一段換成真的。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 執行進場流程後，Discord 收到一則訊息，內含三個商品的開盤價與訊號方向
- [ ] 大台開盤價同時大於小台與微台 → 訊號為**做多**
- [ ] 大台開盤價同時小於小台與微台 → 訊號為**做空**
- [ ] 其他所有情況 → 訊號為**不動作**，含任一相等、兩兩相等、三者相等
- [ ] 訊號計算為純函式，不做任何 I/O，可獨立測試
- [ ] 假 broker 可由測試指定它要回傳的三個開盤價
- [ ] Discord 通知可由設定開關關閉；關閉時不發出任何 HTTP 請求
- [ ] `settings.yaml` 的每個設定項都有對應程式讀取（避免設定與程式漂移，比照 invest-hm 既有做法）
- [ ] 全部測試在**未安裝群益 COM 元件**的機器上可通過
